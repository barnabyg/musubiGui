# Repository guidance

## Agent skills

### Issue tracker

Before reading, creating, or updating tickets, read `docs/agents/issue-tracker.md`. Issues and specs live in GitHub Issues for `barnabyg/musubiGui`.

### Triage labels

Before triaging or changing triage labels, read `docs/agents/triage-labels.md`. Use the five default triage labels.

### Domain docs

Before exploring the codebase, read `docs/agents/domain.md`. Use the single-context layout: root `GLOSSARY.md` and `docs/adr/`.
