# Jobs

Use **Jobs** in the sidebar to select a saved job, create a Wan or H3 draft, or import a configuration. Opening or creating a job shows its dedicated editor without the job list. **Back to jobs** returns to the collection and asks before discarding unsaved edits.

Jobs waits for its library data before enabling creation, selection or import. An initial read failure retries once automatically; if loading still fails, use **Retry loading jobs**.

Each topic has its own page:

- [Job editor and revisions](jobs-editor.md): editor tabs, compact setup, drafts,
  revisions and export versions, configuration review, model conversion, import and
  export, archiving and deleting a job, and focused checks.
- [Training from the Job page](jobs-current-training.md): the current training's
  progress and controls, and how Prepare and start resumes a stopped training.
- [Training settings](jobs-training.md): timestep strategy, optimizer, default
  configuration, presets, caching and alternating Wan high/low LoRAs.
- [Datasets and media in a job](jobs-datasets.md): datasets and repeats, training
  sections and per-dataset resolution, supported media, frame rates, frame extraction,
  H3 images and audio, and repairing reviewed dataset items.
- [Samples and previews](jobs-previews.md): sample memory, previews during training,
  and sample resolution and duration.
- [Checkpoints and disk estimates](jobs-checkpoints.md): checkpoint retention and the
  disk estimate in review.
